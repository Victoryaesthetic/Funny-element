# Funny-element

Небольшой оригинальный стартовый прототип кооперативного платформера на Unity и C#. Это отправная точка для своей игры с двумя персонажами и элементальными препятствиями — без заимствования персонажей, уровней или графики из других игр.

## Запуск

1. Откройте проект в установленной версии Unity 6.6.
2. Откройте любую пустую сцену и нажмите **Play**. Прототип создаёт тестовый уровень автоматически.
3. Для сборки добавьте сцену в Build Profiles / список сцен сборки.

Если проект открывается из пустого репозитория, создайте новый 2D или 3D проект в Unity Hub и скопируйте туда каталог `Assets/Scripts`.

## Управление

- **Ember**: `A` / `D` — движение, `W` — прыжок.
- **Ripple**: `←` / `→` — движение, `↑` — прыжок.
- На сенсорном экране доступны кнопки движения и прыжка для обоих игроков.

Для простоты используется встроенный Input Manager Unity; если в настройках Active Input Handling выбран только Input System Package, переключите на **Both** или **Input Manager (Old)**.

## Что реализовано

- два управляемых персонажа и небольшая тестовая полоса платформ;
- разные элементальные опасности: неподходящая стихия возвращает героя на старт;
- общий выход, который засчитывает уровень, когда оба героя его достигли;
- экранные сенсорные кнопки, созданные во время запуска.

Это прототип механик, а не готовая игра: дальше можно добавить меню, полноценные уровни, анимацию, звук, сохранение прогресса и более удобный мобильный интерфейс.
