# Funny-element

Небольшой оригинальный стартовый прототип кооперативного платформера на Unity и C#. Это отправная точка для своей игры с двумя персонажами и элементальными препятствиями — без заимствования персонажей, уровней или графики из других игр.

## Запуск

1. Откройте проект в Unity 6.6.
2. Откройте пустую сцену и нажмите **Play**. Прототип создаёт тестовый уровень автоматически.
3. Для сборки добавьте сцену в Build Profiles или в список сцен сборки.

Если проект открывается из пустого репозитория, создайте 3D-проект в Unity Hub и скопируйте в него каталог `Assets/Scripts`.

## Управление

- **Ember**: `A` / `D` — движение, `W` — прыжок.
- **Ripple**: `←` / `→` — движение, `↑` — прыжок.
- На сенсорном экране доступны кнопки движения и прыжка для обоих игроков.

## Что реализовано

- два управляемых персонажа и тестовая полоса платформ;
- разные элементальные опасности;
- общий выход с проверкой одновременного пребывания обоих героев;
- экранные сенсорные кнопки.
